# AKRA: Advanced Kinects Responses Algorithm

AKRA is a private AI Assistant and mission command dashboard created by Akash.

## Features
- **Central Admin Console**: Operator management, ban/unban moderation, role promotions, and system stats.
- **Cyber Chat Stream**: Live message feed with Markdown parsing, syntax-highlighted code blocks, and 1-click code copying.
- **Voice Intelligence**: Real-time browser speech recognition and synthesis.
- **Visual Intelligence**: Image and screenshot analysis.
- **Mission Logs & Archival**: Dedicated per-operator workspaces and exportable transcripts.
- **Permanent Knowledge Bank**: Persistent memory and customized rules.

## Installation & Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Run the application:
```bash
python akra.py
```

3. Open in browser:
```
http://localhost:10000
```
